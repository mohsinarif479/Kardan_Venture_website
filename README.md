# Kardan Ventures — Government Contractor & Multi-Disciplinary Infrastructure Portal

Official website and digital tender procurement platform for **Kardan Ventures (Pvt.) Limited** — a premier government contractor and infrastructure solutions enterprise specialized in public sector tenders, heavy civil construction, and enterprise IT hardware provisioning (servers, commercial laptop fleets, laser projectors, desktops, and datacenter hardware).

---

## 🏛️ Company Profile & Core Verticals

- **Government Tender Contracting & Turnkey Execution:**
  Full lifecycle public tender participation under Federal & Provincial Public Procurement Regulatory Authority (PPRA / EPADS) rules, single-stage two-envelope bidding, bank bid bond guarantees, and audit sign-offs.
- **Civil Construction & Infrastructure Engineering:**
  Turnkey civil engineering under **PEC Category C-2** licensing. Structural administrative buildings, commercial complexes, roadworks, stormwater drainage, and MEP services.
- **Enterprise IT Hardware & Datacenter Provisioning:**
  Authorized Tier-1 supply of enterprise rack & blade servers (Dell PowerEdge, HPE ProLiant), commercial fleet laptops (Lenovo ThinkPad, Dell Latitude), high-lumen 4K laser projectors (Epson), interactive 75"/86" touch display panels (ViewSonic), commercial desktop fleets (HP, Dell OptiPlex), Cisco managed switching, and 3-Phase industrial online UPS systems (Schneider/APC).
- **General Order Supply & Strategic Logistics:**
  Bulk institutional supplies, biometric attendance fleets, emergency power diesel generators, and specialized laboratory apparatus.

---

## 🚀 Key Features

1. **Executive Procurement Status Cockpit:**
   Live statistics tracking (450+ Tenders Delivered, PKR 12.5B+ cumulative project value, 99.4% on-time milestone delivery, 65,000+ IT hardware units).
2. **Searchable & Filterable IT Hardware Catalog:**
   Dynamic client-side filtering by category (*Enterprise Servers, Laptops, Projectors, Desktops, Networking, Power*) and full-text keyword search across processors, RAM, warranties, and models.
3. **Interactive Tender Scope & RFQ Estimator:**
   Enables government procurement officers and project directors to configure a formal quotation request with selected hardware quantities, civil covered area, delivery timeline, and tender tracking IDs, generating an instant dossier reference (e.g., `KV-RFQ-2026-XXXX`).
4. **Executed Tenders & Projects Portfolio:**
   Filterable showcase of completed public sector projects across federal ministries, provincial IT boards, defense directorates, and public universities.
5. **5-Stage Contracting Delivery Framework:**
   Transparent methodology detailing pre-bid scrutiny, bid bond packaging, direct OEM sourcing with Manufacturer Authorization Forms (MAF), joint FAT/SAT inspection, and post-delivery 3-to-5 year onsite SLAs.
6. **Statutory Accreditations & Compliance:**
   Full transparency showcasing FBR Active Taxpayer (ATL) status (NTN 7392014-9), STRN, PEC Category C-2 registration, PPRA pre-qualified vendor status, and ISO 9001 / ISO 27001 certifications.
7. **Printable Corporate Capability Statement:**
   Interactive modal with a one-click print-ready capability dossier for government pre-qualification packages.

## ⚡ Deployment to Vercel

This repository is optimized for deployment on [Vercel](https://vercel.com):

### Option 1: Git Integration (Recommended)
1. Push this project to GitHub, GitLab, or Bitbucket:
   ```bash
   git add .
   git commit -m "Initial commit for Kardan Ventures website"
   git push origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository.
4. Next.js is auto-detected. Click **Deploy**.

### Option 2: Vercel CLI
```bash
npm i -g vercel
vercel
```
